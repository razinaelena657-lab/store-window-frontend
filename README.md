# 🧮 Проект №1: Калькулятор в терминале (CLI)

## 📌 Описание
Консольный калькулятор на Python, который принимает числа и знак операции через командную строку. Поддерживает базовые арифметические действия, защиту от ошибок ввода и работу в интерактивном режиме.

## ✨ Возможности
- Поддержка операций: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- Работа с целыми и дробными числами (`float`)
- Защита от деления на ноль
- Обработка некорректного ввода (буквы, пустые строки, неизвестные операции)
- Интерактивный цикл — можно считать примеры подряд без перезапуска
- Выход по команде `q` или `Ctrl+C`
- Второй режим — передача аргументов сразу через командную строку

## 🛠️ Технологии
- **Python 3.8+**
- Только стандартная библиотека (`sys`, `input`) — без сторонних зависимостей

## 📂 Структура проекта
```
calculator-cli/
├── calculator.py        # интерактивная версия
├── calc_args.py         # версия с аргументами командной строки
└── README.md
```

## 🚀 Установка и запуск

### Интерактивный режим
```bash
python calculator.py
```
Пример сессии:
```
=== Калькулятор ===
Доступные операции: +, -, *, /, //, %, **
Введите 'q' для выхода

Первое число (или 'q' для выхода): 15
Операция (+, -, *, /, //, %, **): *
Второе число: 4
Результат: 15.0 * 4.0 = 60
```

### Режим с аргументами
```bash
python calc_args.py 15 "*" 4
# → 60.0

python calc_args.py 10 / 0
# → деление на ноль
```

## 🧠 Как это работает
1. Программа запрашивает первое число → знак операции → второе число
2. Проверяет корректность операции и преобразует строки в `float`
3. Выполняет вычисление с проверкой деления на ноль
4. Выводит результат в читаемом виде (целые числа — без `.0`)
5. Возвращается в начало цикла до команды выхода

# 🖥️ Проект №2: Калькулятор с визуальным интерфейсом (GUI)

## 📌 Описание
Полноценный калькулятор с графическим интерфейсом на библиотеке **Tkinter**. Имеет кнопки с цифрами, операциями, дисплей и обработку ошибок. Выглядит и работает как стандартный калькулятор Windows.

## ✨ Возможности
- Графическое окно с сеткой кнопок (0–9, операции, `=`, `C`, `⌫`)
- Поле ввода (дисплей), показывающее текущее выражение и результат
- Поддержка операций: `+`, `-`, `×`, `÷`, `%`, `.`, скобки
- Кнопка очистки `C` (сброс) и удаления последнего символа `⌫`
- Обработка ошибок без падения приложения (например, деление на ноль)
- Поддержка клавиатуры (опционально — можно добавить)
- Единая цветовая тема и адаптивные размеры кнопок

## 🛠️ Технологии
- **Python 3.8+**
- **Tkinter** — встроенная библиотека GUI (идёт в комплекте с Python)
- Опционально: **ttk** для более современного вида

## 📂 Структура проекта
```
calculator-gui/
├── main.py              # точка входа
├── ui/
│   ├── __init__.py
│   ├── window.py        # создание окна и layout
│   └── buttons.py       # логика кнопок
├── core/
│   ├── __init__.py
│   └── engine.py        # вычисление выражений
└── README.md
```

## 🚀 Установка и запуск
```bash
# Tkinter уже установлен в стандартной сборке Python
# Для Linux (если нет):
sudo apt install python3-tk

# Запуск:
python main.py
```

## 🖼️ Внешний вид (описание)
```
┌────────────────────────────┐
│  [ 123 + 45           ]    │  ← дисплей
├────┬────┬────┬────┬────────┤
│ C  │ ⌫ │ %  │ ÷  │        │
├────┼────┼────┼────┼────────┤
│ 7  │ 8  │ 9  │ ×  │        │
├────┼────┼────┼────┼────────┤
│ 4  │ 5  │ 6  │ -  │        │
├────┼────┼────┼────┼────────┤
│ 1  │ 2  │ 3  │ +  │        │
├────┼────┴────┼────┼────────┤
│ 0  │    .    │ =  │        │
└────┴─────────┴────┴────────┘
```

## 🧠 Как это работает
1. При нажатии кнопки её символ добавляется в строку выражения
2. При нажатии `=` строка передаётся в `core.engine.evaluate()`
3. Внутри используется `eval()` с белым списком символов **или** собственный парсер (безопасный вариант)
4. Результат выводится на дисплей; ошибки (`ZeroDivisionError`, `SyntaxError`) ловятся и показываются пользователю
5. `C` обнуляет строку, `⌫` удаляет последний символ

## 🔒 Безопасность
> ⚠️ Не используйте «сырой» `eval()` для непроверенных данных. В учебной версии допустимо, но для реального проекта лучше:
- Ограничить разрешённые символы regex-ом
- Или использовать библиотеку `ast.literal_eval` / готовый парсер `simpleeval`

# 💱 Проект №3: Калькулятор с конвертацией валют

## 📌 Описание
Расширенный калькулятор, который помимо арифметики умеет **конвертировать валюты по актуальному курсу**. Получает курсы через публичный API, кэширует их и позволяет переключаться между режимами «обычный калькулятор» ↔ «конвертер валют».

## ✨ Возможности
- Всё из проекта №1 (базовая арифметика)
- **Конвертация валют**: USD, EUR, RUB, GBP, CNY, JPY, KZT и другие
- Получение актуальных курсов через API (например, [exchangerate.host](https://exchangerate.host) или [open.er-api.com](https://open.er-api.com))
- Кэширование курсов (например, на 1 час), чтобы не дёргать API каждый раз
- Конвертация как одиночных сумм, так и результата арифметической операции
- Красивый вывод с округлением до 2 знаков и указанием валюты
- Обработка ошибок сети (fallback на сохранённый кэш или сообщение пользователю)

## 🛠️ Технологии
- **Python 3.8+**
- `requests` — HTTP-запросы к API курсов
- `json` — работа с кэшем
- `datetime` — проверка времени жизни кэша
- (опционально) `tkinter` — если нужен GUI для конвертера

## 📂 Структура проекта
```

├── main.py                 # CLI-меню выбора режима
├── core/
│   ├── __init__.py

│   └── currency.py         # логика конвертации
├── api/
│   ├── __init__.py

├── data/
```

## 🖥️ Пример работы
```
=== Калькулятор + Конвертер валют ===
1. Арифметика
2. Конвертация валют
3. Выход
Выбор: 2

Из валюты (например, USD): USD
В валюту (например, RUB): RUB
Сумма: 100

💰 100 USD = 9 250.00 RUB
Курс: 1 USD = 92.50 RUB (обновлено 12:34)
```

## 🌐 Используемое API
**open.er-api.com** — бесплатный, без ключа:
```
GET https://open.er-api.com/v6/latest/USD
```
Ответ содержит объект `rates` со всеми курсами относительно базовой валюты.

## 🧠 Как это работает
1. Пользователь выбирает режим работы
2. В режиме конвертации запрашивается сумма и две валюты
3. Программа обращается к модулю `rates.get_rate(from, to)`:
   - Проверяет кэш (файл `rates_cache.json`)
   - Если кэш свежий (< 1 часа) — использует его
   - Иначе — делает запрос к API и обновляет кэш
4. Вычисляет результат: `amount * rate(from → to)`
5. Выводит с форматированием через `f"{value:,.2f}"`

## 🔒 Обработка ошибок
| Ситуация | Поведение |
|---|---|
| Нет интернета | Используется кэш (даже устаревший) + предупреждение |
| Неизвестная валюта | Сообщение «Валюта XXX не найдена» |
| API вернул ошибку | Показ кода ошибки, без падения |
| Отрицательная сумма | Предупреждение, но расчёт выполняется |
